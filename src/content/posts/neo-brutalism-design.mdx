# Neo Brutalism Design Trends 2026

Neo Brutalism menjadi salah satu style design paling populer untuk website modern karena tampilannya yang berani, playful, dan berbeda dari UI mainstream. Style ini terkenal dengan border hitam tebal, warna mencolok, typography besar, dan hard shadow. 0

## Kenapa Neo Brutalism Populer?

Karena kebanyakan website sekarang terlihat terlalu mirip:
- gradient blur
- glassmorphism
- minimal putih
- card rounded soft

Neo Brutalism hadir sebagai style yang lebih “raw”, unik, dan penuh karakter. Banyak designer menggunakan style ini untuk:
- portfolio
- blog
- landing page
- startup website
- creative agency

## Ciri Khas Neo Brutalism

- Border hitam tebal
- Shadow keras tanpa blur
- Typography besar
- Warna vibrant
- Layout playful
- Sedikit rotasi element
- Card seperti sticker

Contoh warna populer:
- Kuning
- Pink
- Cyan
- Lime
- Orange

## Font yang Cocok

Untuk title:
- Archivo Black
- Bricolage Grotesque
- Anton

Untuk body:
- Space Grotesk
- Inter
